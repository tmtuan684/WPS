# 1.1 REPL Warm-up (no file needed)

Before writing any files, spend five minutes in the Node REPL to feel the difference
between browser JS and Node JS firsthand.

Open a terminal and type:

    node

Then try each of these, one at a time, and predict the output before pressing Enter:

    2 + 2
    const greet = name => `Hi, ${name}!`;
    greet('Tuan')
    typeof process
    process.platform
    window
    document
    .help
    .exit

**What to notice:**
- `window` and `document` throw `ReferenceError` — they're browser-only, not part of
  JavaScript itself.
- `process` works immediately with no `require()` — it's a Node global, always available.
- Everything else (arrow functions, template literals, `typeof`) behaves identically to
  what you already know from the browser console.
