1. Why Headings Matter
Screen readers cannot jump by heading levels here because these are just styled divs.
2. Page Structure
The “headings” below are visually bigger but not exposed as headings to assistive tech.
2.1 Landmarks
These containers are not <header>, <main>, or <footer>, so users can’t navigate by regions.
2.2 Keyboard Navigation
No skip link; keyboard users must tab through the whole nav each time.
3. Example Checklist
  • Visually styled “headings” are not real headings
  • Outline view and SR “jump by heading” won’t work
  • Region navigation is missing
