Demonstrating proper heading structure and landmarks.

1. Why Headings Matter

Screen readers allow users to jump by headings. Proper levels (H1–H6) create a meaningful outline.

2. Page Structure

The structure below uses a single h1, then h2 for sections and h3 for subsections.

2.1 Landmarks

Using <header>, <nav>, <main>, and <footer> provides regions screen readers can jump to quickly.

2.2 Keyboard Navigation

Include a “Skip to main content” link to help keyboard users bypass repetitive navigation.

3. Example Checklist

  • One H1 per page
  • Use H2 for major sections
  • Use H3 for subsections under an H2
  • Don’t skip levels (e.g., H2 → H4)
