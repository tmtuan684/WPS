REGULAR EXPRESSIONS IN JAVASCRIPT

Regex is just a tiny pattern language.

A regular expression describes a shape a string should match — not the exact characters. In JS you write one either as a literal, /abc/, or built dynamically with new RegExp("abc"). Every playground below is live: type a pattern on the left, test text underneath, and watch matches highlight in real time.

core methods you'll use constantly: regex.test(str) → true/false · str.match(regex) → array of matches or null · str.replace(regex, replacement) → new string · regex.exec(str) → one match at a time, with capture groups.
1Literal characters — the simplest pattern

Matching exact text

The plainest regex just spells out the characters it wants, in order. /cat/ matches the exact substring "cat" anywhere inside a string — it does not need to match the whole string.

/ /
The cat sat on the mat.
1 match
2Character classes & quantifiers

Matching a kind of character, and how many

Instead of one exact letter, a character class matches any character from a set. Quantifiers say how many times to repeat the thing before them.

\d = digit\w = word char\s = whitespace. = any char + = 1 or more* = 0 or more? = 0 or 1{n,m} = n to m times
/ /
Call the office at 823-1090 or the hotline 823-9999, not 12-34.
2 matches
3Anchors — ^, $, \b

Matching a position, not a character

^ anchors to the start of the string, $ to the end, and \b to a word boundary (between a word character and a non-word character). Without anchors, "cat" also matches inside "category" — try adding \b around it below.

^ = start$ = end\b = word boundary^...$ = whole-string match
/ /
cat catalog concatenate cat's category cat
3 matches
4Groups, alternation & capturing

Grouping pieces together, and pulling data out

Parentheses ( ) group a sub-pattern and also capture whatever matched, so you can reuse it — e.g. in str.replace() with $1, $2. The pipe | means "or".

(a|b) = a or b(...) = capture group$1 $2 = captured text in replace()
/ /
Contact tuan@rmit.com or support@vendor.com for help.
2 matches

Try this in the console tab of your browser to see capture groups reused in a replacement — swapping "First Last" to "Last, First":

"Tuan Nguyen".replace(/(\w+) (\w+)/, "$2, $1")
// → "Nguyen, Tuan"

Practice exercises

Use the playground modules above (or your own scratch file) to build and test each pattern before checking it against sample strings you invent yourself — a pattern that "looks right" often has surprising edge cases.

LEVEL 1

Literals & classes

  1. Write a regex that matches the exact word "error" anywhere in a string, and test it with .test() against 3 sentences you write, at least one containing "errors" (plural) — does it still match? Why?
  2. Write a regex matching any 4-digit year, e.g. "2026", using \d{4}.
  3. Write a regex matching one or more digits in a row (a whole number of any length) using \d+, and use str.match() to pull every number out of the sentence "I have 3 cats, 12 fish, and 1 dog."
  4. Write a regex matching a single uppercase letter followed by any number of lowercase letters (a capitalized word), e.g. matches "Hanoi" but not "hanoi" or "HANOI".
LEVEL 2

Anchors & quantifiers

  1. Write a regex that matches a string containing only digits from start to end (use ^ and $) — this is how you'd check "is this entire field a number" rather than "does it contain a number somewhere".
  2. Write a regex validating a username: must start with a letter, then 2–14 more letters/digits/underscores, whole string. (Hint: combine ^, a class for the first character, \w{2,14}, and $.)
  3. Write a regex that finds whole-word matches of "run" but not inside "running" or "runner", using \b on both sides.
  4. Write a regex matching an optional "+84" or "0" at the start of a Vietnamese phone number, followed by 9 digits. (Hint: (\+84|0) then \d{9}.)
LEVEL 3

Groups & transformation

  1. Write a regex with two capture groups to split a date string like "2026-07-25" into year, month, day — then use match() or exec() to log each piece separately.
  2. Use str.replace() with a capture group to turn every occurrence of "$100", "$25", etc. into "100 USD", "25 USD" in a sentence containing several dollar amounts.
  3. Write a regex using alternation (png|jpg|jpeg|gif) anchored to the end of a filename ($) to check whether a filename has an image extension. Test it against "photo.png", "notes.txt", and "archive.tar.gz".
  4. Write a password-strength checker (no external libraries) using four separate small regexes — one each for length, uppercase, digit, and symbol — and combine the boolean results, similar to the strength meter from the earlier form-validation lesson.
LEVEL 4

Challenge

  1. Write a single regex with the g flag that extracts every hashtag (e.g. #javascript, #webdev) from a block of sample social-media-style text, returning them as an array.
  2. Write a "redact credit card" function: given a string containing a 16-digit card number (possibly with spaces or dashes between groups of 4), replace all but the last 4 digits with *, keeping the original grouping/spacing.
  3. Write a simple Markdown-to-HTML converter for just bold text: replace every **text** with <strong>text</strong> using one capture group and replace().
  4. Reflection: write 3–4 sentences on when a regex becomes "too clever" — a case where a simple string method (includes(), split(), startsWith()) or a few lines of plain JS would be more readable than a dense pattern.

Simple applications

Four small, realistic uses of everything above — each is a self-contained function you could drop into a real project.

1. Form field validation

The direct continuation of the form-validation lesson: reuse the exact email/phone/password patterns from module 5 above inside an input event handler.

function isValidEmail(v) {
  // same pattern as module 5
  return /^[\w.+-]+@[\w-]+\.[a-zA-Z]{2,}$/.test(v);
}

2. Extracting data from text

Pull every date out of a block of free text, e.g. parsing "meeting notes" for scheduled dates.

const text = "Due 2026-08-01, review 2026-08-15.";
const dates = text.match(/\d{4}-\d{2}-\d{2}/g);
// → ["2026-08-01", "2026-08-15"]

3. Search & replace / masking

Normalize inconsistent whitespace, or mask sensitive data before logging it.

"Hello    world,   Tuan"
  .replace(/\s+/g, " ");
// → "Hello world, Tuan"

"0912345678".replace(/\d(?=\d{4})/g, "*");
// → "******5678"

4. Splitting & tokenizing

Split a messy, human-typed list on any mix of commas, semicolons, and extra spaces.

"apple,  banana; cherry ,durian"
  .split(/\s*[,;]\s*/);
// → ["apple","banana","cherry","durian"]
